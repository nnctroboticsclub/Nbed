# 正規版 v1.0.0 の公開判断

評価日: 2026-10-23 / 対象: v0.6.0

**現時点では v1.0.0 としての公開を推奨しません。v0.6.0 は GitHub のプレリリースとして公開します。**

[SemVer](https://semver.org/lang/ja/#spec-item-5) では v1.0.0 が公開 API を定義する節目です。
すべての STM32 機能に対応する必要はありませんが、保証する対象・API・失敗時の挙動と、
その検証範囲を確定してから互換性を約束することを推奨します。
以下は本ライブラリの品質判断であり、SemVer が実機試験や CI を義務付けているという意味ではありません。

## 確認できていること

| 項目 | 状態 |
| --- | --- |
| 対象 MCU | F303K8、F446RE、F767ZI を明示し、その他をビルド時に拒否 |
| ビルド | 3系列の開発環境とサンプルを用意。結果は各リリースノートに記録 |
| ホストテスト | ピン判定、GPIO、時間、UART、SPI、設定スクリプトなどを確認。F7 はクロック、I²C、ADC1/3 も代替 HAL で確認 |
| 配布 | バージョン付きの署名コミット・タグ、GitHub Release、リリースノートを作成 |
| F7 の初期化 | PLL/APB/Flash の上限、OverDrive、DWT アンロック、I²C の HSI16、専用リンカを実装 |

ホストテストはレジスタや外部回路の動作を再現しません。ビルド成功や内部ループバックの
サンプルがあることも、実機で実行した証拠とは分けて扱っています。
最終確認では回帰テスト31件を実行して成功し、F7 共通ドライバ1件はコンパイル成功後に
Windows のアプリ制御（4551）で実行をスキップしました。既存の任意統合テスト8件も
スキップしています。

## 公開前に解消したい点

| 優先度 | 現在の根拠 | v1.0.0 前に行うこと |
| --- | --- | --- |
| 必須 | 3系列とも、この作業では実機の通信・波形・負荷試験を実施していない。F7 は追加直後 | 対応ボードごとに起動、クロック、GPIO、ADC、PWM、I²C、SPI、UART、CAN、エンコーダ、計時を確認し、機器・配線・結果を記録 |
| 必須 | `Pwm::SendDataDma()` は公開されているが全系列で処理を行わない | 実装するか、予約 API を公開対象から外す／未対応を明示的に返す API に整理する。0.x の間に方針を決める |
| 必須 | `AnalogIn::ReadRatio()` は失敗時にも有効な測定値と同じ0を返す。I²C/UART の通常転送は `HAL_MAX_DELAY` を使う | 測定失敗の通知方法、無期限待機を許す範囲、タイムアウト・復帰方法を確定して文書化する。必要なら API を変更する |
| 推奨 | GitHub Actions の CI 定義がリポジトリにない。既存の任意統合テストは通常実行でスキップ | 固定したツールチェーンでホストテスト・全系列ビルド・利用側ビルドを自動実行し、失敗時に公開を止める |
| 推奨 | ピン競合検出は機能内・タイマ所有権が中心。GPIO と別機能のピン共有や割り込みからの呼び出しを一律には防がない | 排他、割り込み文脈、バッファ寿命、ピン所有権、外部からの HAL 操作の許容範囲を公開 API の契約として整理する |

DMA、Ethernet、USB、全タイマなどの未対応機能自体は、対象外と明示すれば正規版を妨げません。
利用者が使えると受け取る API の挙動と、実際に保証できる範囲を揃えることが重要です。

## 実機検証の完了条件

1. 3ボードで電源投入からの起動、LED、既定コンソール、既定クロックと HSI 構成を確認する。
2. ADC の既知電圧、PWM の周波数・デューティ、エンコーダの正逆カウントを測定する。
3. I²C は実センサ、SPI はループバックと実機器、UART は受信割り込みと長文出力、
   CAN はトランシーバ付き2ノード通信を確認する。
4. 未接続・NAK・受信過負荷・タイムアウト・再初期化・タイマ競合などの失敗時動作を確認する。
5. F7 はキャッシュ設定、216 MHz の OverDrive、SRAM 配置、外部機器の信号品質を確認する。
6. 条件・測定結果・既知の制約を保存し、公開 API を固定してから v1.0.0 の候補を評価する。

実機が使えるまで公開作業全体を止める必要はありません。v0.6.0 のプレリリースを使って
検証を進め、上記の必須項目が完了した時点で正規版へ移行する方針です。
